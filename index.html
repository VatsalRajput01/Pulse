Install Pulse Workspace

Add Pulse Workspace to your home screen or desktop for instant launch and full offline capability:

iOS & iPadOS (Safari)

Tap the browser Share icon in the toolbar, then select Add to Home Screen.

Android (Chrome / Edge)

Open the Browser Menu (⋮) in the top corner and tap Install app or Add to Home screen.

Desktop (Chrome, Edge, or Safari)

Click the Install icon in the address bar, or choose File → Add to Dock in Safari.
